# Week 3 - Full VAPT Cycle

## Overview

This project demonstrates a complete Vulnerability Assessment and Penetration Testing (VAPT) cycle performed in a controlled lab environment.

## Tasks Performed

* Advanced Exploitation (XSS to RCE simulation using Metasploit)
* Web Application Testing (SQL Injection, XSS using DVWA)
* Manual Testing using Burp Suite
* Automated Exploitation using sqlmap
* Post-Exploitation (Shell access and system enumeration)
* Reporting and Evidence Collection

## Tools Used

* Burp Suite
* SQLMap
* Metasploit
* DVWA (Damn Vulnerable Web Application)

## Findings

* SQL Injection (Critical)
* Cross-Site Scripting (Medium)
* Weak Passwords (High)

## Result

Successfully exploited vulnerabilities, extracted database information, and achieved remote shell access.
